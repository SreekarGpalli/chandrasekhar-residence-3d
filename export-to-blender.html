EXPORT TO BLENDER

Builds the procedural house, waits for async assets, and writes a GLB into Blender/chandrasekhar_residence_full.glb.

  1. Start the site: node serve.js
  2. Start the saver: node scripts/export-to-blender.js
  3. This page posts the GLB to http://127.0.0.1:8081/save-glb

After import, run scripts/setup_blender_scene.py only on a fresh GLB — never on the finished realism master.
